# Screenshot Checklist

Capture genuine, unedited screenshots after each workflow succeeds. Keep any secrets, tokens, and personal account details out of view.

- [ ] GitHub branches, feature commit, and merge visible in repository history.
- [ ] Jenkins job configuration with SCM polling and configured JDK/Maven tools.
- [ ] Jenkins successful build stages, test results, and archived JAR artifact.
- [ ] Commit-SHA-versioned artifact from the CI enhancement.
- [ ] GitHub Actions successful run showing build, tests, and uploaded artifact.
- [ ] Ansible playbook execution showing the role and handler results.
- [ ] Local Docker image and running container.
- [ ] Container logs and successful API response.
- [ ] Kubernetes Deployment, Service, and three ready pods.
- [ ] Actual API response through the Kubernetes Service.
- [ ] Five replicas after scaling up.
- [ ] Three replicas after scaling back down.
- [ ] ConfigMap applied and referenced by the Deployment.

Add each image to the report with a caption, date, and the command or UI action that produced it. Mark a screenshot as pending until the real command or workflow has succeeded.
